# Contributing to nucleus

Thank you for wanting to help.  How nucleus is built — its principles,
plan and design — is in [PLAN.md](PLAN.md) and [DOCS.md](DOCS.md); a
change follows the principles first.  Repository content (code, comments,
documents, commit messages) is in English.

-s`), stating that you agree to these terms for it.
